# Earthing and Lightning Protection Report
## Musina 33/11 kV Substation

**Document ID:** MUS‑RPT‑005‑R0  
**Date:** 2026‑06‑11  

### 1. Executive Summary

The earthing grid, last tested in 1998, is likely undersized for the expanded substation footprint. Calculations based on assumed soil resistivity (120 Ω·m) indicate that touch potentials under a 300 A earth fault may exceed IEEE 80 limits. The annual failure of 33 kV surge arresters is traced to elevated surge stress caused by poor earthing. Immediate testing and grid extension are recommended.

### 2. Earthing Grid Analysis

| Parameter               | Value          |
|-------------------------|----------------|
| Grid resistance (calc)  | ~0.22 Ω        |
| GPR (300 A fault)       | ~66 V          |
| Mesh voltage (approx)   | ~43 V          |
| Touch voltage limit     | 286 V          |
| Step voltage limit      | 838 V          |
| Pass/Fail               | Touch → FAIL   |

**Deficiency D‑006:** Touch potential exceeds IEEE 80 tolerable limit.  
**Action:** Soil resistivity measurement, grid resistance test, extend grid, re‑assess.

### 3. Lightning Surge Arrester Analysis

| Parameter                     | Value          |
|-------------------------------|----------------|
| Ground flash density (Ng)     | 12 /km²/yr     |
| Expected strikes/year         | 0.48           |
| Surge energy (10 kA, Class 2) | 43 J           |
| Arrester rating               | 2500 J         |
| Margin under poor earthing    | <2 × → stressed|

**Deficiency D‑007:** Arrester energy absorption capability insufficient for site conditions.  
**Action:** Upgrade to Class 3 arresters after earthing improvements.

### 4. Cost Estimates

- Earthing audit and grid extension: ZAR 35 000.
- Replacement of 3 × 33 kV arresters (Class 3): ZAR 12 000.
